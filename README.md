# משימות · ניהול משימות חכם עם סוכן AI

מערכת אישית לניהול משימות בעברית (RTL), מחולקת למרחבים, עם סוכן AI מובנה.

## מה יש בפנים
- **מרחבים** עם צבע ותצוגה לבחירה: קנבן (גרירה בין סטטוסים), רשימת TODO ממוינת לפי עדיפות, ולוח שנה חודשי (לחיצה על יום יוצרת משימה, גרירה בין ימים).
- **כרטיס משימה**: כותרת, עדיפות (נמוכה/בינונית/גבוהה/דחוף), סטטוס (חדשה/בעבודה/בהשהייה/הושלמה), תאריך יעד, מרחב ופרטים.
- **דשבורד**: בחירת מרחבים (נשמרת), דחוף / להיום / באיחור, וכרטיס סטטיסטיקה לכל מרחב.
- **סוכן AI** (OpenAI, ברירת מחדל `gpt-6-luna`) עם 5 כלים: קריאה, הוספה, עדכון, מחיקה וסיכום. פועל רק על המרחב שנבחר בראש הצ'אט, ומבקש אישור לפני פעולה על יותר מ-3 משימות או לפני מחיקה.
- כניסה עם סיסמה אחת.

## הרצה
```bash
npm install
npm run seed      # יוצר טבלאות ונתוני דוגמה (רק אם המסד ריק; --force לאיפוס)
npm run dev
```

משתני סביבה (`.env`):

| משתנה | תיאור |
| --- | --- |
| `DATABASE_URL` | Postgres |
| `OPENAI_API_KEY` | מפתח OpenAI |
| `APP_PASSWORD` | סיסמת הכניסה |
| `OPENAI_MODEL` | אופציונלי, ברירת מחדל `gpt-6-luna` |
